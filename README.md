## Canvas Engine & PDFCraft Export

| Module | Capability | Output |
| --- | --- | --- |
| Vector Studio | Non-destructive curves, boolean paths, SVG layers | `.svg`, `.eps` |
| PhotoCraft | Local AI inpainting, color grading, RAW import | `.png`, `.tiff` |
| PDFCraft | Multi-page print imposition and CMYK proofing | `.pdf` |

## Offline Workspace Setup

1. Extract the release archive to a local folder with write access.
2. Launch `ArtCraft.exe` to initialize the local model cache.
3. Adjust DPI and color profile inside `files/craft/vector_preset.json`.
